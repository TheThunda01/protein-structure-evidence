# Contributing

Please keep the scientific question, source versions, mapping rules, and limitations visible when changing this example. Run `make test` and `make demo`; update numerical snapshots only after inspecting the cause of a change. Do not replace source files without checking their provenance and data terms.

The first implementation and documentation were developed with AI assistance and checked using executable tests. A passing test is evidence about the implementation, not proof of a biological claim. Describe substantive revisions honestly, and connect scientific statements to primary or authoritative sources.
